# Mode: project - Portfolio Project Evaluation

Score each project idea across 6 dimensions:

| Dimension | Weight | 5 = ... | 1 = ... |
|-----------|--------|---------|---------|
| Signal for target roles | 25% | directly proves target-role skill | unrelated |
| Uniqueness | 20% | almost nobody has done this | everyone has it |
| Demo-ability | 20% | live demo in 2 minutes | code only, not visual |
| Metrics potential | 15% | clear metrics | no measurable output |
| Time to MVP | 10% | 1 week | 3+ months |
| STAR story potential | 10% | rich trade-off story | only implementation work |

## Interview Pack requirements

For each approved project:
1. one-pager
2. demo
3. postmortem

## 80/20 plan

- Week 1 -> MVP with the core metric
- Week 2 -> polish + interview pack

## Verdicts

- **BUILD**
- **SKIP**
- **PIVOT TO [alternative]**
